# Data

`anonymized_har_features.csv` contains derived trial-level features from the original processed smartphone IMU recordings.

Privacy choices:

- raw accelerometer, gyroscope, and gravity time series are not included
- original participant names are not included
- participant IDs are anonymized as `participant_01`, `participant_02`, ...
- collection timestamps and original local paths are not included
- each row is a derived feature vector for one activity trial
